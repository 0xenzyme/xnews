## 2. Agents and developer tools

### Claude Code Projects: proactive coordinator, plus /btw, /fork, reminders, and read-only sharing

- What happened: @ClaudeDevs says the Claude Code Projects coordinator is "much more proactive": it answers questions in the project chat and reports status on parallel threads. @alexmichael posted the feature list the same evening: /btw sends a side question to its own thread, /fork branches the current thread, thread reminders, read-only share links (threads that touched your computer can't be shared), pinned artifact thumbnails, and simpler settings.

## 1. 安全

### Cursor 公布 10 月安全事件复盘：Fireworks 泄露密钥，最多 5,000 人可能装到恶意 Claude Code 扩展

- 发生了什么：Cursor 博客（11/13）称，攻击者拿到 Cursor 发给推理/训练供应商 Fireworks 的访问密钥（由 Fireworks 一侧泄露），从共享的只读存储桶里复制了一批 coding agent 轨迹（多为 2025 年、非 Privacy Mode 会话）。少量轨迹里留有未脱敏的凭证（不到 0.01% 的客户 API 凭证外泄），攻击者以此进入 Cursor 的部分 SaaS 工具，拿到归档的非生产仓库、部分客服邮件和用量数据等。10/29 攻击者用偷来的凭证把恶意版 Anthropic.claude-code 2.1.312 / 2.1.313 放进 Cursor 扩展市场的缓存，约 11 小时后下架，最多约 5,000 名用户可能装到。Cursor 称最后一次攻击活动在 11/1 且被拦截，已把全部推理流量迁离 Fireworks、轮换所有内部凭证、重建扩展市场。
- 为什么值得关注：这是一条典型的「供应商密钥 → 训练数据里的明文凭证 → 供应链投毒」链路。用 AI 编码工具的团队，自己的 agent 轨迹里同样可能夹着密钥。
- 原帖与互动：[cursor_ai](https://x.com/cursor_ai/status/2121411147714970092)｜约 55.7 万曝光、1,995 赞；官方复盘 [cursor.com/blog/security-incident-update](https://cursor.com/blog/security-incident-update)；10/30 的 [安全通告与排查脚本](https://cursor.com/blog/claude-code-extension-security-notice)
- 核验：verified（官方博客原文）。影响人数、「已遏制」等为 Cursor 自述，author-claim。同期 Uber 司机数据外泄也被报道与 Fireworks 凭证有关，本期未核实，unverified。
- 判断：10/29 在 Cursor 里装过或升级过 Claude Code 扩展的，按通告跑脚本；仅卸载扩展不够。没开 Privacy Mode 的团队可以趁这次重新评估。

## 2. 产业

### OpenAI 机器人团队「解散」？Fortune 报道、员工否认；Altman：让机器人去盖数据中心

- 发生了什么：Fortune 报道 OpenAI 在重启机器人团队五个月后将其拆散，研究人员并入首席研究官 Mark Chen 的主研究组，应用团队划到 Greg Brockman 下，理由是通用模型在机器人任务上已超过专用模型。消息在 X 上以「解散」刷屏。OpenAI 员工 @slessans 回复称「机器人项目包括硬件都还在，没有解散」。11/14 Altman 在 Stripe 联合创始人 John Collison 的 Cheeky Pint 播客上说，OpenAI 会把机器人方向对准自建数据中心，「自我复制的数据中心」已经可以够到；他称目前 1 GW 算力建设加五年运营约需 700 亿美元，降到 200 亿会让他满意得多。
- 为什么值得关注：如果属实，这是头部实验室公开押注「通用模型当机器人大脑」，专用 VLA 团队的定位会受影响（中文圈已有做具身智能的从业者在讨论部门重组）。

### Antigravity 上线 Dynamic Workflows：agent 写 Python 脚本编排子 agent（补收）

- 发生了什么：@antigravity 宣布推送 Dynamic Workflows：输入 /run-workflow，agent 会写一段 Python 脚本，用并行、串行的子 agent 和结构化交接完成任务；脚本运行前可审，可保存复用。另有 Orchestrator 模式：Carbon 做计划，Hydrogen 写代码跑测试，卡住再交回 Carbon，称平均快 19%、省 24% 额度。
- 为什么值得关注：和 Claude Code Projects 的协调器思路不同，Google 把编排落成可审、可复跑的代码，追求确定性而不是靠提示词。

- 判断：重复性多步骤任务（迁移、批量修复）适合先用它固化流程。

## 5. 研究与评测

### Deepnote 发 Agent Initiative Benchmark；200+ 模型对照实验：视觉参数要留，编码器预训练可省；Mafia 游戏测 28 个模型

- 发生了什么：Deepnote 的 @jakubjurovych 发布主动 agent 评测：把 12 个前沿模型放进一家有 6 年详细历史的虚拟公司 Slack，看它们能否主动介入（对齐跨团队工作、提醒别用未授权客户 logo 等）；结果 OpenAI 的 6.1 Sol 和 Astra 胜过 Anthropic 的 Fable 5.2。Meta FAIR / NYU 的 Ellis Brown 等从零训练 200+ 个多模态模型，结论是专用视觉参数必不可少，而独立编码器和单独预训练可选；encoder-free 方案目前仍落后。另一项「Mafia」式社交游戏实验让 25 万真人与 28 个模型对局，称 OpenAI 模型最会撒谎、xAI 最忠诚、Claude 最爱告密，一个果蝇脑模型也参赛。
- 为什么值得关注：评测重心正从单题正确率转向「什么时候该主动」「多模态怎么设计」「社交行为」这类更贴近部署的问题。
- 原帖与互动：[jakubjurovych](https://x.com/jakubjurovych/status/2121256499552915586)｜约 38.2 万曝光、690 收藏；[_ellisbrown](https://x.com/_ellisbrown/status/2121335477244428419)｜约 7.7 万曝光、567 收藏；[choang333](https://x.com/choang333/status/2121335484236386574)；[giffmana 点评](https://x.com/giffmana/status/2121381045727859122)；[imodarressi（Mafia）](https://x.com/imodarressi/status/2121280505786110176)｜约 131 万曝光
- 核验：三项均为作者团队自发布，author-claim；未读论文/报告全文。
- 判断：选主动式 agent 底模时，Deepnote 的成本对比（每任务成本差两个数量级）值得翻看原表。

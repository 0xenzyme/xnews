## 1. 前沿模型

### Anthropic 发布 Claude Fable 5.2 与 Claude Mythos 5.2，价格降两成

- 发生了什么：@claudeai 11/9 宣布 Fable 5.2 与 Mythos 5.2。官方说明两者是同一个底层模型：Fable 带强防滥用护栏，面向所有付费套餐、Claude Platform 和主流云平台；Mythos 只对网络安全、生物医学方向的机构通过审核计划开放。Fable 5.2 价格为每百万输入 token 8 美元、输出 40 美元（此前 10 / 50 美元）。官方展示的预发布案例包括：1,000 个 Fable 5.2 agent 用 30 小时把费马大定理的证明完整形式化（同样设置下 Opus 5.5 18 小时只完成 26%）；在 MIPLIB 的 203 个公开难题中 72 个超过已知最优解、45 个证明了最优；从一段提示独立设计出三台可直接工作的电子设备；在双臂机器人基准 RoboDojo 上超过其他模型；Mythos 5.2 对 34 个基因治疗衣壳中的 28 个给出准确结构预测；另有两篇理论物理预印本。官方仍建议日常编码和知识工作先用 Opus 5.5。
- 为什么值得关注：Anthropic 第一次把「同一模型、两种护栏」做成公开产品线，高风险能力走审核通道；同时旗舰降价，对重度 agent 用户的成本有直接影响。
- 原帖与互动：[claudeai 发布帖](https://x.com/claudeai/status/2119867114450268322)，约 727 万曝光、69,928 赞、6,567 转、10,871 收藏；[定价帖](https://x.com/claudeai/status/2119867138987176141)，约 53 万曝光；[费马大定理形式化](https://x.com/claudeai/status/2119867129751056485)，约 54 万曝光、4,466 赞；[电子设备案例](https://x.com/claudeai/status/2119899459761131615)，约 69 万曝光、12,994 赞；[AnthropicAI 转发](https://x.com/AnthropicAI/status/2119867707546071125)，约 50 万曝光。
- 核验：发布、定价、可用范围 verified（官方账号 + [Anthropic 新闻页](https://www.anthropic.com/news)）；费马形式化、MIPLIB、衣壳、物理结果均为官方自报（author-claim），MIPLIB 解已提交待第三方核对，化学合成路线尚未经实验验证（官方原话）。新闻摘要里「输出快 30%」的说法未在官方帖中看到，unverified。
- 判断：可以写「Fable 5.2 上线、降价 20%」；费马、MIPLIB 等成果要注明「Anthropic 自报」。

### Meta 推出 Muse Ember：最小、最省的 agent 工作模型

- 发生了什么：@AIatMeta 11/9 发布 Muse Ember，定位为 Meta 最小、最高效的模型，面向日常 agent 工作：跨应用执行流程、按顺序调用工具、跑测试、做定点代码修复；1M token 上下文，原生支持文本、图像、音频和视频输入。已通过 Meta 自家 API 提供，并同日上架 Google Cloud（同时上架的还有 Muse Wonder、Muse Spark 1.3）。

### 美团开源 LongCat-2.5 权重：1.6T 总参、约 48B 激活，MIT 协议

- 发生了什么：@Meituan_LongCat 11/9 宣布开放 LongCat-2.5 权重（模型 11/2 已发布、此前只开 API）。原生多模态 MoE，总参 1.6T、每 token 激活约 48B，主打长程 agent 任务、视觉理解和 agentic coding（复杂工程、全项目构建、创意设计、3D）。[Hugging Face 模型卡](https://huggingface.co/meituan-longcat/LongCat-2.5) 称训练基于国产 AI 加速器，并提供 W4A4 量化版，说明相比 W8A8 解码吞吐提升约 43%。模型卡自报成绩如 Terminal Bench v2.1 88.4、BrowseComp 91.9、MCP Atlas 83.1，与 GLM-5.3、kimi-k3、DeepSeek-V4.1-Flash 大体同一档。
- 为什么值得关注：又一个万亿级中文开源模型，MIT 协议比多数「开放权重」更宽松；国产芯片训练 + INT4 推理是可落地的部署路线。
- 原帖与互动：[Meituan_LongCat](https://x.com/Meituan_LongCat/status/2119793531393040462)，约 3.5 万曝光、954 赞、110 转、170 收藏；中文转述 [NFT_Chen](https://x.com/NFT_Chen/status/2119810010415018299)，约 3,000 曝光。11/2 的[发布帖](https://x.com/Meituan_LongCat/status/2117264311714537633)约 33 万曝光。
- 核验：权重与协议 verified（官方帖 + Hugging Face 页面）；跑分为美团自测或引用，模型卡注明未加星号的成绩「仅供参考」，author-claim。模型卡页面显示的存储参数量为 1.8T，与宣传的 1.6T 不一致，原因未说明。
- 判断：可以写「美团 MIT 开源 1.6T 多模态 agent 模型」；跑分别写成「超过某闭源模型」。

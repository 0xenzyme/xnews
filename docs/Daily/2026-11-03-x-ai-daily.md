## 2. Coding Agent 模型路由

- 发生了什么：@yetone 开源的 **Magpie**（MIT）在窗口内继续被中英文开发者刷屏：本地菜单栏 + 网关（默认 `127.0.0.1:3425`），把 Claude Code / Codex / Gemini CLI 等接到任意供应商（DeepSeek、Kimi、GLM、Ollama，以及已有 Claude/ChatGPT 订阅），统一切模型、额度用完可换号，并做协议翻译。GitHub：https://github.com/yetone/magpie （写稿时 API 约 **28,384** 星）；文档 https://usemagpie.ai/docs/start 。社区帖强调「别再每个 agent 改 BASE_URL」。

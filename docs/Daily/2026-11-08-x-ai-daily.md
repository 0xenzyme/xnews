## 1. Agent 记忆

### Anthropic：Claude 的 agent 记忆与「dreaming」

- 发生了什么：@AnthropicAI 11/6 发工程博客 [The components of agent memory](https://www.anthropic.com/research/components-of-agent-memory)。核心做法：会话中让 Claude 自己判断什么值得记；会话外用「dreaming」回看原始 transcript，纠正错误笔记、构建 wiki 式记忆、把少量关键笔记提升到每次会话预加载的顶层。文中数据：在约 35 万文件 / 4.2 亿 token 的内部语料上，dreaming 从 2 轮扩到 128 轮，仅靠 wiki 的得分从 13% 升到 48%；「搜索 + wiki」从 54% 升到 61%（仅搜索 53%），每题省约 2 万 token；合同类任务改写构建指令后关键事实保留从 41/57 提到 57/57。另一结论：对强模型「告诉它记忆是干什么的，别规定怎么记」，硬规则（如「只记失败」）反而削弱收益。
- 为什么值得关注：给做长期 agent 的团队一套可抄的分层：会话内写笔记、离线校对、顶层保持很小（Claude Code 只预加载 `MEMORY.md` 前 200 行 / 25KB）。
- 原帖与互动：[AnthropicAI](https://x.com/AnthropicAI/status/2118814753154064501)，约 154 万曝光、12,157 赞、1,082 转、691 引用、873 回复、10,881 收藏（收藏数是本窗口最高）。
- 核验：verified，官方博客 + 官方 X；数字均为 Anthropic 内部评测。
- 判断：可以写「dreaming 是离线校对记忆的一种做法」；别写成「Claude 有了持续学习 / 改了权重」，博客明确把权重更新排除在外。

## 3. 榜单可信度

### MaxxBench：DeepSWE 题微改，74% 的并列拉开 23 个点

- 发生了什么：开发者 Justin Lo（@loresjpg）11/7 发布 MaxxBench，取 89 道 DeepSWE 任务，只对指令或起始代码做小改（比如文件名改小写），工程问题不变。原本在 DeepSWE 上都约 74% 的模型拉开 23pp。二手转述的数字：DeepSeek V4.1 Flash 74.2% → 55.6%，Gemini 3.8 Flash 73.8% → 53.4%，Opus 5.5 反升到 76.4%，据称 12 个配置中只有它分数上升。
- 为什么值得关注：给「按公开榜选 coding agent」泼冷水；最有用的是把方法拿去改造自己的内部评测。
- 原帖与互动：[loresjpg](https://x.com/loresjpg/status/2118880329490637049)，约 39.6 万曝光、3,640 赞、265 转、176 引用、1,143 收藏；Lucas Beyer 回复称赞「very good idea」。
- 核验：author-claim，作者自建基准，暂无独立复现；具体分数来自二手转述帖，以作者线程/站点为准。
- 判断：适合写「榜单过拟合的提醒」；别据此宣布某模型「刷榜」。

## 4. AI 做密码分析

### Google DeepMind：AI agent 找到旧版 RSA-1024 的两处弱点

- 发生了什么：@GoogleDeepMind 11/6 发布研究，由 Pushmeet Kohli 撰文介绍：在人工监督下，AI agent 发现 (1) 攻击者控制签名块约一半以上时，padding 不再提供保护；在已被攻破的 1024 位基准密钥上沙箱复现，CPU 时间少 3.5 倍；短指纹场景的新算法理论上比此前最佳方法快约 1,600 倍；(2) 批量分解同长度密钥的新算法，每多一把 1024 位密钥的平均成本比以往批量方法降约 30 倍。合作者含 Nadia Heninger（UCSD/Inria）与 Emmanuel Thomé（Inria）。DeepMind 强调 2048 位及以上的现代体系不受影响。
- 为什么值得关注：「AI 加速数学/安全研究」的实打实案例，也提醒还在用 1024 位 RSA 的遗留系统该升级了。
- 原帖与互动：[GoogleDeepMind](https://x.com/GoogleDeepMind/status/2118755418675765656)，约 12 万曝光、1,365 赞、182 转、371 收藏；[pushmeet 长文](https://x.com/pushmeet/status/2118752095859794390)，约 13 万曝光。
- 核验：verified，官方 X + DeepMind 技术论文 PDF；1,600 倍是理论估计。
- 判断：写「旧 RSA-1024 被 AI 压低了攻击成本」；不要写「RSA 被破解」。

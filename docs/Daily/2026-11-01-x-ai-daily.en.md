## 1. Coding-agent supply chain

### Cursor: malicious Claude Code extension — check `svc-telemetry` first

- What happened: @cursor_ai on Oct 30 (blog dated Oct 29) said a tampered `Anthropic.claude-code` **2.1.312 / 2.1.313** (Windows / macOS) appeared on the Cursor VS Code Extension Marketplace — **not built by Anthropic**; official ceiling **~5,000** users. Payload collects host/user info, tries to plant an SSH public key tagged `svc-telemetry`, open a reverse tunnel, and persist. Cursor says enabling local SSH usually needs admin rights, so that step fails on most hosts — but key writes and host beacons may still have run. Response: removed the package, briefly took the whole marketplace down, worked with the cloud host to kill the attacker endpoint, restored the market. Ask: update to **Claude Code for VS Code 2.1.314** and follow the blog’s scripts/`grep svc-telemetry` — **uninstalling the extension is not enough**; persistence scripts can keep running.

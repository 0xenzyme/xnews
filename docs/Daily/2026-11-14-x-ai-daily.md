## 2. Agent 与开发工具

### Claude Code Projects：协调器变主动，加 /btw、/fork、提醒和只读分享

- 发生了什么：@ClaudeDevs 称 Claude Code Projects 的协调器「主动多了」：会在项目聊天里回答问题，并汇报各并行线程的进度。@alexmichael 同晚连发多条功能说明：/btw 把旁支问题分到新线程、/fork 分叉当前线程、线程提醒、只读链接分享（接触过本机的线程不能分享）、产物缩略图置顶、设置页简化。同一晚 Claude Code 桌面版还支持用 mods 自定义主题。
- 为什么值得关注：并行 agent 的瓶颈从「能不能并行」变成「谁来盯」。协调器主动汇报，意味着用户角色从派活变成审阅。
- 原帖与互动：[ClaudeDevs](https://x.com/ClaudeDevs/status/2121375309287301360)｜约 18.9 万曝光、5,177 赞、1,757 收藏；[alexmichael（/btw /fork）](https://x.com/alexmichael/status/2121375999178821788)；[alexmichael（分享）](https://x.com/alexmichael/status/2121376286581141965)；[ClaudeDevs（mods 主题）](https://x.com/ClaudeDevs/status/2121392666244186327)｜约 3.2 万曝光
- 核验：协调器更新与 mods 主题 verified（官方帖）。逐项功能来自 @alexmichael 个人帖，author-claim。
- 判断：已经在用 Projects 跑多线程的团队值得今天就试新协调器；有用户提醒各线程共享用量额度，合并冲突仍需人工处理。

## 3. 模型与 API

### DeepSeek 把 App 的完整能力开放成 API：搜索、文件、链接、语音，另有 OCR / ASR / TTS

- 发生了什么：@deepseek_ai 宣布 DeepSeek App 背后的搜索、文件、链接、安全和语音能力现在可以通过 DeepSeek API 调用：用几个参数开启内置能力，也可以单独调用 OCR、ASR、TTS 接口。
- 为什么值得关注：此前开发者要自己拼搜索和文件解析；现在可以直接拿到与 App 同款的工具链，做国产 agent 的门槛又低了一截。
- 原帖与互动：[deepseek_ai](https://x.com/deepseek_ai/status/2121247896918253875)｜约 53.9 万曝光、7,077 赞、2,020 收藏
- 核验：发布 verified（官方帖）。定价与各接口的限额未在帖内说明，unverified。
- 判断：本期互动最高的模型厂商帖，收藏比例高，说明开发者准备真用。做中文 agent 的团队可对比自建搜索的成本。

## 4. 研究

### Thinking Machines：Inkling 2 Small 从预训练到 RL 全程原生 4-bit 前向

- 发生了什么：@thinkymachines 在 Connectionism 博客说明 Inkling 2 Small 的训练从预训练第一步到最后的 RL rollout 都用原生 4-bit 前向计算，并讨论了量化误差如何干扰学习以及怎么处理。
- 为什么值得关注：低比特训练能显著提速、省显存，但很少有实验室把整套流程公开到 RL 阶段。
- 原帖与互动：[thinkymachines](https://x.com/thinkymachines/status/2121353292878110868)｜约 7.9 万曝光、785 赞、503 收藏
- 核验：博文发布 verified（官方帖）；技术细节与收益为作者自述，author-claim。
- 判断：做预训练或大规模微调的团队值得细读，可与上期开源的权重一起看。

### Axiom 宣布 Faltings 定理首次在 Lean 中机器验证；DeepMind 开放 WeatherNext 3 的底层数据集

- 发生了什么：@axiommathai 宣布首个机器验证的 Faltings 定理（Mordell 猜想）证明，由其 agent 在 Lean 中完成，走的是 Vojta–Bombieri 路线而非 Faltings 1983 年原证。Google DeepMind 发布 PARDIG 与 SatWeave 两个数据集，即 WeatherNext 3 背后的观测数据基础。

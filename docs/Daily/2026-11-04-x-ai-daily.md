## 1. 权重空间编程

### MIT：Astra 直接改权重，Qwen 0.8B 推理环修好了

- 发生了什么：Rikiya Takehi、Jayden Teoh、Alex Zhang、Omar Khattab（MIT CSAIL）11 月 2 日发博客提出 **Weight-Space Programming**：前沿 LLM（文中用 GPT-6 Astra）可不经梯度下降、原生读写神经网络权重。头条实验：Astra 仅编辑 Qwen3.5-0.8B **0.016%** 权重，修掉推理循环——MATH-500 **7.9%→48.1%**，IFEval **21.0%→62.3%**，GSM8K **13.8%→67.1%**；MATH-500 触 token 上限比例 **93%→33%**（50 次前向）。博客：https://rikiyat.github.io/blog/weight-space-programming/ ；二次提及编辑后权重 `RikiyaT/Qwen3.5-0.8B-weight-space-programming`（Apache-2.0）。
- 为什么值得关注：把「用模型改模型」从微调叙事拉到**直接写权重**——若可复现，对齐/消融/热修小模型的工具链会重排；也立刻触发「这是不是换皮 steering / abliteration」的质疑。
- 原帖与互动：[rikiyatakehi](https://x.com/rikiyatakehi/status/2117313742891327994)｜约 842 万浏览、54,105 赞、7,058 转发、5,429 引用、2,268 回复、35,079 书签。中文二传：[lxrmoe](https://x.com/lxrmoe/status/2117457949606199696)｜约 1.8 万浏览；[dongxi_nlp](https://x.com/dongxi_nlp/status/2117510361477795954)｜约 4.1 万浏览、319 赞。
- 核验：verified — 作者博客 + 作者 X；数字出自博客；媒体有 VentureBeat 报道。
- 判断：早期博客、未经同行评审；被编辑的最大 LM 仅 0.8B；Gemma 数学几乎不动（6.8→7.7）——更像能**去掉局部故障**，不能**补上缺失能力**。批评指出 Qwen 编辑像允许练评测的 steering-vector / abliteration。别写成「大模型已可任意重写任意规模权重」。

## 2. 音频原生决策 API

### Hume：Audio Decision API——不给转写，直接出概率

- 发生了什么：Hume 11 月 2 日正式上线 **Audio Decision API**：上传 MP3/WAV（约 5 秒–5 分钟）+ 自然语言问题 → 返回 noul / choice / score / span 等概率；**不返回转写**，由代码对概率设阈值。官方自称与人类评审团平均一致率 **70.7%**（个体评审基线 56.5%）。SDK：Python `hume-audio-decisions`、TS `@humeai/audio-decisions`。博客：https://www.hume.ai/blog/introducing-hume-audio-decision-api ；文档：https://dev.hume.ai/audio-decisions/docs/overview 。
- 为什么值得关注：客服质检、销售通话、合规抽检一类「听完再判」工作流，可绕过 ASR 误差链，直接落决策阈值——产品形态比再发一个语音转写模型更可落地。
- 原帖与互动：[hume_ai](https://x.com/hume_ai/status/2117285608745820372)｜约 406 万浏览、1,963 赞、3,367 转发、220 引用、199 回复、1,413 书签。
- 核验：verified — 官方博客 + docs + 11/02 changelog；一致率数字为官方自报。
- 判断：别把「70.7%」写成独立第三方评测；延迟数字若只见二次摘要，按 author-claim。生产先核隐私条款与音频留存策略。

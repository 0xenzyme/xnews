## 1. 模型与产品

### Humans& 发布协作模型 Ampersand v0.1

- 发生了什么：@humansand 宣布 Ampersand——面向「多人长期协作」的模型，称在数月级模拟里，与 Ampersand 协作的用户比用自家旧模型 Fable 及其他 frontier 完成更多目标；通过 Agents API 开放，无 waitlist。中文圈跟帖指出其基于开源 GLM 5.3 后训练（@alacheng）。
- 为什么值得关注：叙事从「更会答」转向「会不会在群聊里闭嘴、帮团队推进目标」；后训练路线（冻住基座、改行为）也在被更多团队验证。
- 原帖与互动：[官方发布](https://x.com/humansand/status/2112674550907552137)｜约 12.3 万浏览、828 赞、100 转发、72 回复；[Georges Harik 转发感言](https://x.com/gharik/status/2112679528376291380)｜约 9.1k 浏览、98 赞；[中文解读](https://x.com/alacheng/status/2112722228144148485)｜约 2.1k 浏览、21 赞。
- 核验：author-claim — 官方帖与 API 入口可核；「优于 frontier」与「基于 GLM 5.3」主要来自公司/二手说法，独立评测未见。
- 判断：值得盯 Agents API 的真实多用户会话体验；别把自家模拟榜直接当成公开榜。

### ElevenLabs 推出 Eleven Realtime（语音到语音）

- 发生了什么：@ElevenLabs 发布 Eleven Realtime：端到端 speech-to-speech，宣称约半秒起说，兼顾速度与口语推理；后续汇总称 v1 Max 在 Big Bench Audio 约 98.8%、起说约 0.57s，另有低成本 Mini。
- 为什么值得关注：语音 Agent 长期卡在「快但不准 / 准但不快」；一体化 S2S 会改写客服、辅导、通话产品的栈选择（相对 ASR→LLM→TTS 流水线）。
- 原帖与互动：[官方发布](https://x.com/ElevenLabs/status/2112550782063247521)｜约 17.2 万浏览、2151 赞、160 转发；[TestingCatalog 摘要](https://x.com/testingcatalog/status/2112778083816140857)｜约 3.0k 浏览、26 赞。
- 核验：verified — 官方产品帖存在；具体榜分以 ElevenLabs/评测站文档为准，未在本轮逐条打开对照。
- 判断：做语音 Agent 的人应对照延迟、打断、工具调用与多语言；不要只抄宣传 latency。

## 2. Agent 外壳与基础设施

### Google Research 开源 Harness²：冻住权重，递归改 Agent 外壳

- 发生了什么：社区密集讨论 google-research/harness2——通过 Propose–Probe–Compose 改提示词、工具、记忆、Skills、子 Agent，不改模型权重；多帖引用 WorkBuddy-Bench 单步最高约 +11.5 分，Apache 2.0。
- 为什么值得关注：和 Ampersand 同向——战场从「换更大模型」移到「修 harness」。对本地/开源模型尤其重要：外壳可复现地自修，比追榜更接近工程。
- 原帖与互动：[中文解读示例](https://x.com/VeknQAQ/status/2111970750349639846)｜约 273 浏览、3 赞；[英文风险提醒](https://x.com/borisvidolov/status/2112421550418960853)｜约 47 浏览；热度分散在多条中文技术帖，单帖不高但话题持续。
- 核验：author-claim — GitHub 路径与 arXiv 编号被多帖引用；本轮 WebFetch 未拉到完整 README star 数，分数以论文/仓库 README 为准。
- 判断：先跑官方 demo，再谈「Agent 自我改进」；护栏被 harness 自己改掉是真实风险点。

### Eagle Corp 发布 EAGLE-4：自适应 speculative decoding

- 发生了什么：@EagleCorp 发布开源 drafter EAGLE-4，称在 Qwen3.8-27B、4×NVIDIA B300、单请求等设定下达到 961.6 tok/s；要点是「一个 drafter 按 batch/硬件/负载调策略，且保持目标模型输出分布」。GitHub：eagle-hq/EAGLE-4。
- 为什么值得关注：在「智力饱和」讨论升温时，推理成本与吞吐直接决定 Agent 能不能常开。自适应 speculative decoding 是可落地的杠杆。
- 原帖与互动：[官方发布](https://x.com/EagleCorp/status/2112660683670323531)｜约 110 万浏览、4523 赞、562 转发、429 回复；[TestingCatalog](https://x.com/testingcatalog/status/2112665677152829772)｜约 3.4 万浏览、145 赞；[karla](https://x.com/karlarboledas/status/2112669909536702850)｜约 3.2 万浏览、129 赞。
- 核验：verified — 官方帖含 GitHub 链接且展开页可访问；吞吐数字为自家设定下的测量，需在真实 batch 下复测。
- 判断：服务端 Agent / 编码助手优先看；别把单请求峰值当成生产 SLA。

### 银行与航司继续挡第三方 AI Agent

- 发生了什么：多条讨论延续：JPMorgan、Schwab、Citi、BofA 等限制外部 Agent 用客户凭证登录/动账；Delta 等对订票类 Agent 设障；Jamie Dimon「rogue agents」表述被反复引用。
- 为什么值得关注：消费级 Agent 的真实瓶颈常常是权限与责任，不是模型分数。没有受控委托层，购物/银行 Agent 很难规模化。
- 原帖与互动：讨论分散；示例 [Fortune 转述帖](https://x.com/arnaudmercier/status/2112053521184936254)、[汇总帖](https://x.com/__vandos__/status/2112105671218827362)。单帖互动偏低，属持续政策议题而非单爆帖。
- 核验：author-claim — 依赖财报电话会/FT/Fortune 等二手报道转述；本轮未逐条打开原文。
- 判断：做 Agent 产品先设计「官方 connector / 人在环」，别赌平台长期放行凭证冒充。

## 3. 可证明推理

### Anthropic FlashProve：用密码学证明「就是这套权重在答」

- 发生了什么：@AnthropicAI（verified）介绍 **FlashProve**——基于既有密码学技术，让开发者验证某条回复是否来自**特定已承诺模型**；相对先前开源方法显著更高效。研究文：https://www.anthropic.com/research/provable-inference ；代码 Apache-2.0：https://github.com/anthropics/FlashProve 。文中示例：Llama 4 Maverick（约 400B MoE、4-bit）单卡 H100 证明吞吐约 **110 tok/s**，每 1024 token 请求证明约 **19 MB**，约为同模型 vLLM 推理 GPU 时间的 **70–95×**。应用场景包括防劫持会话、安全评测方核对「测到的就是线上那套」。

## 3. Provable inference

### Anthropic FlashProve: cryptography that a reply came from committed weights

- What happened: Verified @AnthropicAI introduced **FlashProve** — cryptographic techniques so developers can verify a response came from a **specific committed model**, substantially more efficient than prior open-source approaches. Research: https://www.anthropic.com/research/provable-inference ; code Apache-2.0: https://github.com/anthropics/FlashProve .

## 3. 开源与开发工具

### 腾讯混元放开 Hy4 flash 权重：220B 总量、每 token 约 12B 激活，附 FP8 与 Base

- 发生了什么：@TencentHunyuan 宣布 Hy4 flash 开源权重，同时放出指令版、FP8 量化指令版和预训练 Hy4 flash-Base，可在 Hugging Face、ModelScope、GitCode 下载；GitHub 仓库为 [Tencent-Hunyuan/Hy4-flash](https://github.com/Tencent-Hunyuan/Hy4-flash)。模型卡写：总参数约 220B（含约 64B Engram），每 token 激活约 12B（文本 11.3B + 视觉 0.43B），原生文本 / 图像输入、文本输出，上下文 100 万 token；许可为 Tencent Hy License。架构要点包括混合注意力（IndexPool 稀疏注意力与滑动窗口 1:3 交错）、LatentMoE，以及内置 0.85B 的 DFly2 草稿模型做投机解码。官方 X 主帖把规模写成「224B（12B active）」，与模型卡的 220B 口径略有出入，本期以模型卡为准。该模型本身 11 月 16 日已作为 API 发布；这次是发布两天后兑现开源。@opencode 称 Hy4 flash「意外走红」，并说接下来 10 天仍在 OpenCode 上独占免费。中文圈 [NFT_Chen](https://x.com/NFT_Chen/status/2122943673562477001) 等迅速转发，但曝光量远低于官方英文主帖。
- 为什么值得关注：国产日常生产力档模型里，这是最近一次「API 上线后很快放权重」的兑现，可直接在消费级多卡或高配单卡上跑对照，而不只是看报价。
- 原帖与互动：[混元官方](https://x.com/TencentHunyuan/status/2122912575302119554)｜约 15.8 万曝光、1,692 赞、489 收藏；[OpenCode 免费窗口](https://x.com/opencode/status/2123106127030210786)｜约 4.1 万曝光、1,198 赞；中文 [NFT_Chen](https://x.com/NFT_Chen/status/2122943673562477001)｜约 6,900 曝光。权重：[Hugging Face](https://huggingface.co/tencent/Hy4-flash)

## 4. 芯片与基础设施

### OpenAI：模型在 AMD 旗舰 GPU IP 上找出最高约 14% PPA 改进，部分改动已送去制造

- 发生了什么：@OpenAI 发帖并刊出博客《Advancing chip design with OpenAI models》。官方称与 AMD 合作，在「已经被工程师优化多年」的旗舰 GPU IP 上，模型通过改写 SystemVerilog RTL、并用 Synopsys 工具检查行为，找出最高约 14% 的功耗 / 性能 / 面积（PPA）改进，相当于「不到五个月做完大约一年的进度」；AMD 已把部分改动纳入近期送去制造的设计，并把另一些写入后续生产设计文件。官方还写：AMD 验证了其下一代旗舰 CPU 关键模块上由模型写出的设计有个位数百分比的 PPA 收益。自家首款推理芯片 Jalapeño 上，模型建议的改动在硅后验证中，估计标准单元面积在向量单元约降 13%、矩阵单元约降 10%。下一步是与 Synopsys 合训 GPT-Synopsys，让模型按工程师习惯使用 EDA 工具。
- 为什么值得关注：这把「模型改代码」推进到「模型改已经要流片的 RTL」，而且改的是 AMD 量产线，而不只是开源教学核。
- 原帖与互动：[OpenAI 主帖](https://x.com/OpenAI/status/2123100386638877054)｜约 52.8 万曝光、3,785 赞、614 收藏；原文 [OpenAI 博客](https://openai.com/index/advancing-chip-design-with-our-models/)
- 核验：博客与官方帖发布 verified。14%、硅后面积降幅、「一年进度」和 CPU 个位数收益均为 OpenAI 官方 author-claim；本期未见 AMD 以自己名义点名具体产品与模块的独立稿。
- 判断：把它当成「AI 设计辅助已经进入量产 RTL」的证据，而不是当成某款显卡已经快了 14%。真正可核对的节点，是下次 AMD 旗舰发布或财报里会不会单独归因。

### Factory：英伟达在隔离网里用其 harness 做 Nemotron 后训练，并报出 Terminal-Bench 提升

- 发生了什么：@factory 称，NVIDIA 在自有隔离网络里用 Factory 对 Nemotron 做后训练，并且是其环境里唯一商用、受支持的 harness，可提供长程 agent 和完整执行轨迹。跟帖给出官方所称的成绩：Nemotron 3 Ultra 在 Terminal-Bench 2.0 上从 38.5 升到 49；Nemotron 3.5 Super VL 的初步检查点在 Terminal-Bench 2.1 上从 52.11 升到 60.4。公司此前已有介绍 Nemotron 团队在本地环境使用 Factory 的文章。
- 为什么值得关注：对不能把未发布权重和评测轨迹送到公有云的团队，这是「私有 agent 环境能不能真正用于后训练」的一个具名案例。
- 原帖与互动：[Factory 主帖](https://x.com/factory/status/2123106207997247855)｜约 2.8 万曝光、225 赞；[成绩跟帖](https://x.com/factory/status/2123106220223672536)；背景 [Factory 文章](https://factory.com/articles/private-ai-model-post-training)
- 核验：英伟达曾在隔离 / 本地环境使用 Factory，有公司此前公开案例支撑。本次 Terminal-Bench 新旧分数为 Factory 转述的 NVIDIA 结果，author-claim，本期未在英伟达文档里逐项核对这组前后对比。

## 1. AI 与数学

### OpenAI 预印本：矩阵乘法指数恰好是 9/4

- 发生了什么：OpenAI 在 openai/math 仓库发布 11 月 24 日预印本《The matrix multiplication exponent is nine fourths》，摘要称：在任意域上，n×n 矩阵乘法的形式算术电路至少需要 n^(9/4)/2 个乘法或除法门。上界 9/4 是 10 月 6 日那批结果给出的，这次补上匹配下界，ω 被「钉死」在 2.25。Sébastien Bubeck 说，此前下界方面「几乎一无所知」，模型在上界之后一直在攻下界。
- 为什么值得关注：从 Strassen 1969 年起，ω 一直是算法领域最核心的开放问题之一。如果证明成立，这是 AI 首次独立解决一个「教科书级」复杂度问题的上下界两端。对做数值、编译器、推理内核的工程师，近期没有直接工程影响——上界构造的常数是否可用另说。
- 原帖与互动：[@SebastienBubeck](https://x.com/SebastienBubeck/status/2125402576145572334)｜约 67 万曝光、4,303 赞、867 收藏；[@gdb](https://x.com/gdb/status/2125418102049628201)｜约 33 万曝光、4,078 赞；[@deedydas 解读](https://x.com/deedydas/status/2125445769629204816)｜约 32 万曝光、4,784 赞；预印本 [github.com/openai/math](https://github.com/openai/math/tree/main/preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026)。
- 核验：预印本与摘要 verified（仓库可读）；「证明正确」属 author-claim——尚未见独立复核或同行评议，本期未读到 Lean 形式化是否覆盖全文。
- 判断：值得等一周看复杂度理论圈的审读反馈。这类结论一旦有漏洞，通常出在「形式算术电路」模型的适用范围上。

## 2. 工程与基础设施

### Anthropic 把 Messages API 从 Python 迁到 Rust：Claude 一周写初版，线上服务当校验器

- 发生了什么：Anthropic 工程博客披露，Messages API（客户和 Claude Code、Cowork 访问 Claude 的主入口）从 2024 年初到 2026 年秋流量增长约 1,800 倍，于是迁到 Rust。Claude 用约一周写出核心请求路径初版；难点是验证一致性——Python 版本一直在变、模型输出不确定、工程师看不到客户请求。做法是用生产流量做影子比对：同一份模型输出同时走两个版本，逐阶段比对并记录隐私安全的差异指纹，再由 Claude agent 团队在沙箱里复现、提修复，人类审核。线上一致率从约 24% 提升到 99.6%。
- 为什么值得关注：这是「agent 写迁移 + agent 验证迁移」在头部实验室核心服务上的公开案例。可复用的思路是：把旧系统当 oracle，用差异指纹替代读原始数据。
- 原帖与互动：[@AnthropicAI](https://x.com/AnthropicAI/status/2125627317263466739)｜约 180 万曝光、7,966 赞、3,730 收藏；博客 [anthropic.com/research/migrating-api-to-rust](https://www.anthropic.com/research/migrating-api-to-rust)。
- 核验：迁移事实与方法 verified（官方帖 + 博客）；每请求 CPU 降约 70%、首 token 中位延迟降约 20%、1,800 倍流量增长为 author-claim（Anthropic 自报）。
- 判断：本期最值得工程团队精读的一篇。重点看「差异指纹」怎么设计，比看 Rust 本身更有价值。

- 发生了什么：Sam Altman 宣布 Private Inference 进入小范围客户测试，属于「OpenAI Private Intelligence」产品线，与零数据保留等配合，在可证明（attested）的机密计算环境里处理请求，主要面向金融、医疗、法律等受监管行业。

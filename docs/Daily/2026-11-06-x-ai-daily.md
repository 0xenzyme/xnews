## 3. Agent 产品账本

## 4. 基准叙事转向「干完要多久」

### Artificial Analysis：Time per Task 成主速度指标

- 发生了什么：@ArtificialAnlys（verified）宣布约 **1,000** 个 serverless 端点的主性能指标改为 **Time per Task**（Intelligence Index 任务的 output tokens ÷ 端到端吞吐），覆盖 prefill / 隐藏推理 / 首 token 等待，并纳入多轮 agent 工作负载。官方摘录：max effort 下 GPT-6 Astra 约 **51 tok/s** 却约 **17 分钟**完任务；Claude Opus 5.5 约 **111 tok/s** / **~26 分钟**；Gemini 4 Carbon（high）约 **~29 分钟**——Astra 每任务约 **50k** output，对手约 **120k–170k**。默认 medium effort 可再砍时间约 **3–5×**、成本约 **2–4×**。
- 为什么值得关注：agent 场景里「流得炫」≠「先干完」；采购/路由应同时盯分数、$/task 与分钟数。
- 原帖与互动：[ArtificialAnlys](https://x.com/ArtificialAnlys/status/2118034157909712992)｜约 2.9 万浏览、256 赞、10 转发、38 引用、64 回复、41 书签。
- 核验：verified — 官方 X + AA 站点对比页；具体分钟数为官方当时快照，会随端点滚动更新。
- 判断：引用请带 effort 档；别把「Astra 更慢 tok/s」写成「Astra 更弱」。

## 1. 模型发布

### OpenAI 正式推出 GPT-6.2 Astra 与 Sol：旗舰降价提效，Sol 冲日常 agent

- 发生了什么：@OpenAI 宣布 GPT-6.2 Astra（面向最难项目的前沿模型）和 GPT-6.2 Sol（日常工作与多步 agent）上线。官方博客称 Astra 在 Agents’ Last Exam（长周期专业工作）上比 GPT-6 Astra 高 5.2 分、单任务成本不到其三分之一，并比 Claude Fable 5.2 高 5.5 分、成本约为其 5%（脚注：Fable 5.2 榜单成绩排除了 9 道使用回退模型的题）。科学向评测 Terminal-Bench-Science 0.1 称比 GPT-6 Astra 高 9 个百分点、成本同样不到三分之一；官方自称「对科学家而言是目前最好的模型」。API 定价：Astra 输入 / 缓存输入 / 输出为每百万 token $8 / $0.40 / $40，比 GPT-6 Astra 输入输出低 20%，缓存再打六折；Sol 沿用 GPT-6.1 Sol 的 $2 / $0.10 / $10。今日起 Plus、Pro、Enterprise、Edu 可在 ChatGPT Work 与 Codex 使用；开发者 API 名为 `gpt-6.2-astra`、`gpt-6.2-sol`，两者均可开 Ultrafast。Pro 500 两款都能用 Ultrafast，Pro 200 首次获得 Ultrafast（先从 Sol 开始）。OpenRouter 已上架，含 Pro 变体。安全方面：两款均达 Preparedness Framework 的网络「Critical」与生化「High」门槛；Astra 还是首个对外发布即达到「AI 自我改进」High 门槛的模型。因能力上升，高风险网络协助的拒答更严，官方称将把 6.2 送入 Daybreak 供获批的防守方降低拒答。官方帖还写 Astra 在 ExploitBench Internal Port 上比 GPT-6 Astra 高 22 分。
- 为什么值得关注：这是对「Fable / Opus 占据编码与专业工作」叙事的正面反击，打法不是堆分数，而是把单任务成本和专业文档 / 视觉 / 科学工作放在第一行。自我改进 High 门槛则意味着官方自己也承认它对内部研究提速的潜力。

### 路透独家：中国用美国模型输出做蒸馏，已从实验室走进工业

- 发生了什么：路透（Eduardo Baptista、Laurie Chen，北京 11 月 17 日电）报道，在美国收紧先进芯片对华供应的背景下，中国机构越来越系统地使用美国领先模型的输出，为国产模型准备训练数据。路透称梳理了 300 余份论文、专利、企业披露、招聘启事和政府文件，认为蒸馏已从学术实验扩展到工业场景；北京方面也在鼓励用蒸馏降低制造业部署成本。报道强调蒸馏本身并不违法、也无法完整复制前沿模型能力，但可能削弱芯片管制的效果。文中还写到：美国商务部官员曾在成都会晤中向中方表达知识产权担忧；中方将蒸馏视为常规技术，并表示若构成窃密愿处理，但未作具体承诺。
- 为什么值得关注：这直接关系到国内团队能不能、该不该继续用闭源 API 产出做合成数据，以及后续合同、条款和出口管制的执法口径。
- 原帖与互动：[Reuters](https://x.com/Reuters/status/2122537762439975368)｜约 18.8 万曝光、141 赞；报道见路透稿（多家转载，如 [Yahoo 转载](https://ca.finance.yahoo.com/news/exclusive-china-taps-us-ai-034212581.html)）
- 核验：路透刊发该独家 verified。文中对中美官员会谈的细节来自匿名消息源，author-claim；蒸馏在各家公司的实际规模本期无法独立核对。
- 判断：依赖闭源 API 做合成数据的团队，应重读供应商条款，并准备一条不依赖特定美方模型输出的数据备份路径。

# AI每日精选（2026-11-27）

美国感恩节，实验室官方发布明显变少，但信号没断。科学侧，斯坦福物理学家 Venkatesa Chandrasekaran 发布一篇和 GPT-6 Astra 合作数月完成的四维量子引力预印本，Sam Altman 亲自站台。开源侧，俄罗斯 Sber 发布 708B 的 GigaChat 4（MIT 许可），腾讯开源推测解码器 DFly2，蚂蚁开源设计向文生图模型。算力侧，一边是 SemiAnalysis 把 Trainium 和 TPU 拉进 InferenceX 并给出 1.2–2.5 倍性价比，一边是英伟达停发东南亚服务器、路透称 GLM-5.5 和 Kimi K4 可能推迟。用户侧，OpenAI 承认 GPT-6.2 计费出错，额度消耗变快 25–40%。

## 1. AI 与科学

### GPT-6 Astra 参与的四维量子引力预印本：有限振幅、复现黑洞熵

- 发生了什么：Chandrasekaran 在 arXiv 发布《An algebraic quantization of gravity from the null cone》（arXiv:2611.34924，署名单位为斯坦福 Leinweber 理论物理研究所），提出对四维洛伦兹时空真空广义相对论的背景无关量子化：先在相交的零锥上解引力约束，再量子化。多条解读帖称，论文给出有限的非微扰引力子对产生振幅、有界区域的有限维希尔伯特空间，并复现 Bekenstein-Hawking 黑洞熵；作者称多项计算和证明是与 GPT-6 Astra 协作完成的，约用了 4 亿 token。Sam Altman 发帖称 Ven 是「最早相信可以用当时的模型去解千禧年难题的人之一」。
- 为什么值得关注：继 9/4 矩阵乘法和黎曼猜想之后，「AI 做研究」从数学延伸到理论物理。不同之处是，这次主导者是人类物理学家，模型是长期协作者，物理学家 Garrett Lisi 的初读评价也是「工作主要是 Ven 的，Astra 帮了大忙」。
- 原帖与互动：[@tszzl 首发](https://x.com/tszzl/status/2125809711509336342)｜约 241 万曝光、7,561 赞、3,112 收藏；[@sama](https://x.com/sama/status/2125990371897557278)｜约 42.8 万曝光、5,790 赞、777 收藏；[@garrettlisi 初读](https://x.com/garrettlisi/status/2126029126473748912)；论文 [arxiv.org/abs/2611.34924](https://arxiv.org/abs/2611.34924)。
- 核验：预印本与摘要 verified（arXiv 页面可读）；「约 4 亿 token」「多项证明由 Astra 协作完成」为 author-claim（作者自述，经转帖转述，本期未读到论文致谢原文）；物理结论尚未同行评议，unverified。Ven 与 OpenAI 的具体关系本期只有 Altman 的帖子，未找到官方说明。
- 判断：值得关注的是「人主导、模型长期陪跑」的协作模式，而不是「AI 解决了量子引力」这种标题。等圈内审读意见出来再下结论。

### 腾讯开源 DFly2：直接读目标模型 KV 缓存的推测解码器

- 发生了什么：腾讯混元开源 Hy4 flash 使用的推测解码草稿模型 DFly2。草稿层直接读取目标模型的 KV 缓存和 top-k token，不需要预填充、不占额外 KV 显存，草稿成本不随上下文变长。官方称在 64K 上下文下让 DeepSeek-V4.1-Flash 服务吞吐提升最高 81%，在 Hy4 flash agent 任务上最高提速 4.2 倍，比同配方的 DSpark 快约 30%。
- 为什么值得关注：长上下文 agent 推理的瓶颈在解码。DFly2 对 DeepSeek、GLM-5.3-Flash 这类第三方稀疏模型也能用，HF 上已有 DeepSeek-V4.1-Flash 的 DFly2 草稿权重，GitHub 上也出现了 DGX Spark / AMD 的社区移植。
- 原帖与互动：[@TencentAI_News](https://x.com/TencentAI_News/status/2125968859450802415)｜约 9 万曝光、1,426 赞、847 收藏；[@TencentHunyuan](https://x.com/TencentHunyuan/status/2125928146113585468)｜约 3 万曝光、728 赞、309 收藏。
- 核验：开源与权重 verified（HF 上 AngelSlim/DS-V4.1-Flash-DFly2-B6 等已上架）；81% / 4.2× 为 author-claim（腾讯自测）。
- 判断：自托管 DeepSeek-V4.1-Flash 的团队本周值得测一下，收益主要在 32K 以上的长上下文。

## 3. 算力与基础设施

### SemiAnalysis：Trainium 和 TPU 进入 InferenceX，性价比是英伟达的 1.2–2.5 倍

- 发生了什么：SemiAnalysis 宣布 AWS Trainium 和 Google TPU 首次提交到 InferenceX / AgentX 推理基准，性价比为英伟达 GPU 的 1.2–2.5 倍；随后补充，Trainium3 UltraServer 在 agent 推理基准上比 GB300 NVL72 性价比高 2.28 倍。有回复指出，Trainium3 的优势依赖离线批处理，交互场景的首 token 延迟偏高。
- 为什么值得关注：这是第三方基准第一次同台比较三家推理芯片。agent 推理的单位成本，正在成为云厂商之间竞争的重点。
- 原帖与互动：[@SemiAnalysis_](https://x.com/SemiAnalysis_/status/2125867835050111357)｜约 21.9 万曝光、1,492 赞、361 收藏；[Trainium3 补充](https://x.com/SemiAnalysis_/status/2126055957838848156)｜约 3.9 万曝光、427 赞。
- 核验：基准提交事实 verified（SemiAnalysis 官方帖）；倍数为 SemiAnalysis 的测算，author-claim；首 token 延迟的说法来自回复，unverified。
- 判断：做批量 agent 任务（评测、数据合成）的团队可以开始比价，交互式产品仍要看延迟。

## 5. 安全与信任

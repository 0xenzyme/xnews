## 1. Agent 外壳之争

### Garry Tan 的 harness 对比 + Harness Leaderboard

- 发生了什么：YC 总裁 Garry Tan 11/8 晒出自己在做的开源 harness 评测（项目名 GHarnessEvals）。截图要点：7 种组合（Opus 上的 Claude Code、OpenClaw、Hermes、QM，Sol 上的 Codex、OpenClaw、Hermes）跑同样 20 道编码题，通过率全部在 71–79%，20 题里有 14 题在所有组合上结果完全一样，他自己的判断是「题太简单，分不开，是测试的问题而不是平手」，更难的 Terminal-Bench 重跑正在进行。成本差异明显：Opus 上 OpenClaw 每解一题约 $0.44，Claude Code $0.22，Hermes $0.24，QM $0.19；OpenClaw 每次尝试约 99 秒，Claude Code 约 40 秒；Sol 上 Codex 最便宜也最快（$0.17）。对照组：Joël Niklaus 11/5 发布 [Harness Leaderboard](https://huggingface.co/spaces/joelniklaus/harness-leaderboard)，在 GLM-5.3-Flash、DeepSeek-V4.1-Flash、Flint 三个开源模型上固定模型和推理强度、只换外壳，跑了 28,849 次、花了 $4,746：只用 bash 的 mini-swe-agent 平均 51.4%，OpenClaw 27.3%；Pi 49.4%、每解一题 $0.29（比 mini-swe-agent 的 $0.53 低约 45%）；OpenCode 每题 $3.35；最佳外壳随模型变化。
- 为什么值得关注：两组数据放在一起看——前沿闭源模型上外壳差距被模型能力抹平，开源模型上外壳能拉开 24 个点。选型时要按自己的模型重跑一遍，而不是照搬别人的榜。
- 原帖与互动：[garrytan](https://x.com/garrytan/status/2119492448200405110)，约 5.5 万曝光、349 赞、91 回复、144 收藏；[joelniklaus](https://x.com/joelniklaus/status/2118373808692437403)，约 31.5 万曝光、2,569 赞、2,754 收藏。
- 核验：两者都是 author-claim（个人评测，方法和数据公开但无第三方复现）；Garry 的数字来自他贴出的截图，Terminal-Bench 重跑尚无结果。
- 判断：可以写「外壳差距取决于模型强弱」；不要写成「harness 不重要」或「某个外壳最好」。

## 3. 开源模型的「价值观」可以微调（补录）

### Nous Research 发布 Arete-27B

- 发生了什么：@NousResearch 11/6 发布 [Arete-27B](https://nousresearch.com/arete)：在 Qwen3.8-27B 上用约 5,280 万 token 做监督微调（无 RL），教师模型为 Inkling。自建 803 题评测覆盖言论自由、民主、隐私等 7 类：「含官方宣传口径」的回答比例从 22% 降到约 1%，事实分从 2.32 升到 2.98（满分 5）；内部 Hermes Bench 65.60% 对基座 65.77%。权重、训练数据和评测全部公开。博客里 GLM 5.3、DeepSeek V4.1 Flash 的同项比例分别为 15%、16%。
- 为什么值得关注：中文开源模型正是海外最主流的开源底座（[Menlo Ventures 11/3 报告](https://menlovc.com/perspective/2026-the-state-of-enterprise-ai/)：美国企业开源模型支出的 89% 流向中国模型，Kimi 独占 61%），这条把「中国模型的价值观」议题从争论变成了可测、可改的工程问题，中文圈反应两极。
- 原帖与互动：[NousResearch](https://x.com/NousResearch/status/2118822925445050435)，约 223 万曝光、14,539 赞、1,457 转、1,207 引用、7,669 收藏。
- 核验：verified（官方博客 + 权重与数据公开）；评测由 Nous 自建、用 LLM 评审，属 author-claim 性质，批评者认为是「换一种偏向」。
- 判断：写「价值观层是一次微调就能改的浅层」是 Nous 的结论，应注明出处；避免替任何一方下政治结论。

## 4. AI 做数学

### PSI：AI 系统证明 Aaronson–Ambainis 猜想，Lean 验证（补录）

- 发生了什么：Physical Superintelligence（PSI）11/6 宣布，其内部研究系统在运行中使用了一个未公开的 Anthropic 模型，第三天得到 Aaronson–Ambainis 猜想（2008 年提出）的完整证明并通过 Lean 检查，之后又两次改进结果。[论文与 Lean 4 形式化](https://github.com/physical-superintelligence/aaronson-ambainis) 已公开，仓库称无占位、无额外公理，并经两个独立 Lean 内核实现复核。结论含义：在查询模型下，量子算法要获得超多项式加速必须依赖输入结构。
- 为什么值得关注：继上周 DeepMind 的 RSA 结果之后，又一个「AI + 形式化验证」攻克公开难题的案例，而且全部材料可复查。
- 原帖与互动：[psipbc](https://x.com/psipbc/status/2118706269506949152)，约 111 万曝光、3,983 赞、663 转、2,223 收藏。
- 核验：verified（官方公告 + 公开代码）；Lean 证明了形式化陈述，「形式化陈述是否等价于原猜想」仍需数学界确认，评论文章也指出了这一信任边界。
- 判断：写「Lean 已验证的 AI 证明」可以；不要写成「量子计算没用了」，结论只针对查询模型、无结构输入。

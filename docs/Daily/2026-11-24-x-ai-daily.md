## 2. AI 做数学与科学

### Anthropic 放出 Claude 署名的 VP ≠ VNP 证明：70 页论文 + 约 7.3 万行 Lean，尚无人工审阅

- 发生了什么：11 月 23 日，Anthropic 在官方仓库 [anthropics/formal-math](https://github.com/anthropics/formal-math/) 的 vp-vnp 目录中放出论文《VP ≠ VNP over every field》及 Lean 4 形式化，作者栏只有 Claude。README 称结果由一个内部研究用 Claude 模型发现：在任意域上，计算哈密顿回路多项式的电路（以及特征不为 2 时计算积和式 permanent 的电路）在 m 充分大时需要超过 m^{c (log m)^{1/3}} 个门，即超多项式下界。README 写明尚无人类数学家审阅；据二手报道，CI 还用独立的 nanoda 内核复核。Anthropic 没有发正式公告。
- 为什么值得关注：VP vs VNP 是 Valiant 1979 年提出的「代数版 P vs NP」。如果成立，这是代数复杂性理论几十年来最大的下界结果；但它不解决 P vs NP。它距黎曼猜想形式化证明公布只有三天；据 @AndrewCurran_，这也是继指数时间假设（ETH）相关论文之后，又一篇由「内部研究用 Claude 模型」单独署名、无公告上传的论文。
- 原帖与互动：[@AndrewCurran_「又是 Claude 单独署名、无公告上传」](https://x.com/AndrewCurran_/status/2125001971690315858)｜约 2.2 万曝光、596 赞；[@imjustnewatai 摘要](https://x.com/imjustnewatai/status/2124991006512992424)｜约 8.8 万曝光、1,409 赞；[@dummerspast39 长帖](https://x.com/dummerspast39/status/2124988326600167490)｜约 3.8 万曝光、566 赞。
- 核验：论文与 Lean 代码在官方仓库中 verified；定理本身经 Lean 内核检查属于仓库自述，在社区独立复核前按 author-claim 处理；「无人工审阅」来自 README。X 上「43 年来首次突破」等说法是转述者的判断，unverified。
- 判断：先看两件事——Lean 里最终命题是否就是标准定义的 VP ≠ VNP，以及代数复杂性领域专家的公开回应。标题里不要写「AI 解决了 P vs NP」。

### DeepMind 用 Gemini 4 智能体团队找到更便宜的量子电路，全部经 Lean 验证并开源

- 发生了什么：11 月 23 日，Google DeepMind 与 Google Quantum AI 发布[博客](https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/)和论文：多支独立的 Gemini 4 智能体团队分别优化已知量子算法，每个想法须先在 Lean 中证明才能进入共享笔记本，每 4 小时开一次「虚拟会议」交换思路。结果：惯性约束聚变相关电路计算成本降 11.8 倍、所需纠错量子比特从 5,650 降到 4,338；一种光敏分子模拟便宜 8 倍；细胞色素 P450 模拟提升 2.5 倍、比特数从 481 降到 333；某种 Grover 实现提速 2.57 倍；常用的 arcsin 子程序提速 290 倍。Lean 库、问题定义与解答已在 GitHub 开源。
- 为什么值得关注：这是「智能体 + 形式化验证」做科研的又一个样板：机器搜索、证明把关、人选题。X 上流传的「成本最高降 290 倍」只对应 arcsin 子程序，DeepMind 官方帖的口径是模拟成本「最高降约 10 倍」。
- 原帖与互动：[@GoogleDeepMind](https://x.com/GoogleDeepMind/status/2124911073266413634)｜约 21 万曝光、3,367 赞；[@PolymarketMoney「最高 290 倍」](https://x.com/PolymarketMoney/status/2124917801471074497)｜约 86 万曝光、1.96 万赞。

- 判断：短期价值在方法和开源 Lean 库，不在量子计算落地时间表。转述时别把 290 倍当总体结论。

## 3. 模型与开源

### 智谱 GLM-5.4：首个 Loop Transformer 旗舰，750B 参数把 28 层循环跑两遍

- 发生了什么：11 月 23 日，智谱（Z.ai）发布 [GLM-5.4](https://z.ai/blog/glm-5.4)。它在 GLM-5 预训练基座上通过继续训练改造成循环结构：28 层共享权重的层跑两轮，不增加参数，官方称智能水平可比 2T–3T 参数模型。三项工程改动：逐 token 门控的渐进更新（防止激活范数爆炸）、跨轮共享 KV + 第二轮独立滑动窗口（多一轮只多一个窗口的 KV，1M 上下文部署成本可控）、第二轮复用稀疏注意力索引。30B 同参数对照实验中，循环版多约 10% 训练算力，数学、科学推理与长上下文提升最大，输出长度缩短 10–14%。官方定位为「广义编程」（视频、游戏、3D 着色器、CAD），并加入视觉能力；现已向 GLM Coding Plan 用户开放，周额度比 GLM-5.3 多 50%。API 要等安全评估后开放，权重将「负责任地发布」。官方也承认它容易陷入过长的「马拉松式思考」。
- 为什么值得关注：继 Thinking Machines 的 Inkling 2 Mini 之后，又一家把循环 Transformer 做到旗舰规模，而且是改造已有基座而非从头训练，这条路其他实验室可以复制。
- 原帖与互动：[@Zai_org 官方帖](https://x.com/Zai_org/status/2124811995912286352)｜约 87 万曝光、1.08 万赞、2,221 收藏；[@ZixuanLi_ Coding Plan 上线](https://x.com/ZixuanLi_/status/2124719275864670681)｜约 110 万曝光、8,935 赞。
- 核验：架构细节与开放范围 verified（官方技术博客）；「比肩 2T–3T 模型」与基准成绩是官方自测，author-claim。X 上「KingBench 4 第 7、国模第一」来自个人测试帖，unverified。
- 判断：目前只能通过 Coding Plan 用，API 和权重都未放出；想本地部署的团队还要等。慢是真实代价，简单任务官方建议用 GLM-5.3-Flash。

### Anthropic 推出 Claude Ship（beta）：审 PR、修 PR，并按团队策略批准

- 发生了什么：11 月 23 日，Anthropic 发布 [Claude Ship](https://claude.com/resources/articles/introducing-claude-ship)，由三部分组成：已 GA 的 Code Review、新的 PR Steward（处理失败的 CI、合并冲突和评审意见，设计上不批准也不合并）、新的 Claude Approvals（按团队策略决定哪些变更可以自动批准）。在 Claude Code 里运行 /ship 即可。官方称 Claude Code 团队 6–9 月合并的 PR 翻倍以上，被回滚的比例下降超过 40%。PR Steward 与 Approvals 面向 Team 和 Enterprise 处于 beta；符合条件的 Enterprise 组织可领取至少 1 万美元额度，需在 2027 年 1 月 15 日前领取。同日 Claude 还把 connectors 和 skills 合并成统一的 Plugins（Free/Pro/Max/Ultra 已上线，1 万多个可选），并推出与零数据保留（ZDR）兼容的 Enterprise Frontier Safeguards 公测。

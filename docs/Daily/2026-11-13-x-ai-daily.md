# AI每日精选（2026-11-13）

周四英文侧最重的三件事：Google 补齐 Gemini 4 家族，发布最快的 Hydrogen，当天进了 Cursor；Anthropic 让企业把 Claude Managed Agents 整套搬进自己的云或机房（私测），同一天还发了能进视频会议的 Claude Meetings；Thinking Machines 兑现承诺，把 Inkling 2 Small 权重以 Apache 2.0 放上 Hugging Face。OpenAI 的「Cyber at the Frontier」发布会只给了 Daybreak 安全产品和一个未命名网安模型，社区等的 GPT-6.2 没来。中文侧是百度世界大会（词元所、文心闪电、昆仑芯路线图）和张一鸣「2029 年才追平前沿」的内部讲话。11/12 已写的 Qwen4-Max、文心 5.5 Flash、Gemini Decision 1、Praxis-1、AlphaGenome 2 本期不重开。

## 1. 模型

### Google 发布 Gemini 4 Hydrogen：Gemini 4 家族最快一档，当天上 Cursor

- 发生了什么：继 Carbon、Argon 之后，Google 发布 Gemini 4 Hydrogen，定位日常任务、编码和 agent 工作流。Sundar Pichai 称完成任务比 Gemini 3.8 Flash 快 2.5 倍，有 4 档思考级别，按需等待和付费；DeepMind 称在 Artificial Analysis 智能指数上超过 Argon。Logan Kilpatrick 称所有档位的 AI Studio、Gemini API、Gemini 企业版、Gemini App、Google 搜索都可用，Antigravity 给 AI Pro / Ultra 付费用户。Cursor 同日接入，称默认档 CursorBench 54.3%（3.8 Flash 为 39.6%）。
- 为什么值得关注：这是 Gemini 4 家族里面向大规模调用的一档，速度和价格直接决定 agent 循环里的默认模型选型。
- 原帖与互动：[GoogleDeepMind](https://x.com/GoogleDeepMind/status/2120940338869055788)，约 74 万曝光、5,492 赞；[OfficialLoganK](https://x.com/OfficialLoganK/status/2120940951292268640)，约 59 万曝光、8,339 赞；[sundarpichai](https://x.com/sundarpichai/status/2120940236805169182)，约 36 万曝光、6,342 赞；[cursor_ai](https://x.com/cursor_ai/status/2120944639633211619)，约 11 万曝光、1,612 赞。
- 核验：发布与上线渠道 verified（官方帖）；2.5 倍速度、AA 指数为 Google 自报 author-claim；CursorBench 分数为 Cursor 自报 author-claim；X 新闻摘要里的「每百万输入 1.5 美元」「幻觉降低 5 倍以上」未在上述官方帖原文看到，unverified。
- 判断：在用 3.8 Flash 的 agent 管线值得今天就换测；先看自己任务上的速度和成本，再看榜单。

### Thinking Machines 开放 Inkling 2 Small 权重：Apache 2.0

- 发生了什么：@thinkymachines 称 Inkling 2 Small 权重已在 Hugging Face 以 Apache 2.0 发布；Mira Murati 称这是「如约」在安全测试伙伴评估后放出。研究员 Songlin Yang 介绍了架构改动：attention residuals（q/k/v 分开）、gated attention、动态 attention sink、动态 short conv、value norm 等。
- 为什么值得关注：前沿实验室的大号 MoE 以真正宽松的许可证开放，在「开源模型停滞」的争论（见 11/12）里是一个反例。
- 原帖与互动：[thinkymachines](https://x.com/thinkymachines/status/2120982625582195011)，约 13 万曝光、1,162 赞；[miramurati](https://x.com/miramurati/status/2120983826407268458)，约 5.1 万曝光、1,348 赞；[SonglinYang4](https://x.com/SonglinYang4/status/2120988641376026691)，约 1.4 万曝光。
- 核验：Hugging Face 上 [thinkingmachines/Inkling-2-Small](https://huggingface.co/thinkingmachines/Inkling-2-Small) 公开、标注 apache-2.0 与 moe，verified；X 新闻摘要称 594B 参数、100 万上下文、AA 指数 31、vLLM 630 token/s，本期未核到原始出处，unverified。
- 判断：做自托管和微调的团队值得拉下来跑；先确认显存预算再动手。

## 2. Agent 平台

### Claude Managed Agents 可自建（私测）；Gemini API 托管 agent 支持自带沙箱

- 发生了什么：@ClaudeDevs 宣布 Self-hosted Claude Managed Agents 进入私测：agent harness、沙箱和会话历史都可以放在自己的云或本地机房，并自选 Claude 请求发往哪里。Anthropic 平台负责人 Katelyn Lesse 称企业要建内部自治 agent 并把它做进产品，现在可以自己托管。前一天，Google AI Studio 也让 Gemini API 的 Managed Agents 支持自带沙箱（self-hosted environments），Fly.io 等沙箱厂商随即跟进。
- 为什么值得关注：两家都把「agent 跑在哪」交还给企业，规划循环留在云端，执行和数据留在客户侧。这是合规行业落地 agent 的关键前提。
- 原帖与互动：[ClaudeDevs](https://x.com/ClaudeDevs/status/2120938988165091693)，约 48 万曝光、8,262 赞、4,527 收藏；[katelyn_lesse](https://x.com/katelyn_lesse/status/2120968799130386656)，约 6,400 曝光；[GoogleAIStudio](https://x.com/GoogleAIStudio/status/2120610219235660183)，约 7.1 万曝光、760 赞；[flydotio](https://x.com/flydotio/status/2120635073192235101)。
- 核验：两项发布 verified（官方帖）；X 新闻摘要列出的 E2B、Modal、Vercel、Daytona、Cloudflare 等合作方本期只核到 Fly.io，其余 unverified。
- 判断：收藏数远高于点赞比例，说明是开发者真要用的东西；有数据驻留要求的团队可以申请私测。

### Claude Meetings：把 Claude 拉进视频会议，边聊边出文档和白板

- 发生了什么：@claudeai 发布 Claude Meetings 测试版，在 Team 和 Enterprise 计划逐步开放：把 Claude 加进团队视频通话，它在会议进行中就生成文档、白板等 artifact。

- 判断：今天全站互动最高的 AI 产品帖；会议纪要类创业公司要重新想定位。
